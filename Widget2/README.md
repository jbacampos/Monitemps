# MoniTemps

Projeto local baseado **exatamente** nos três arquivos fornecidos pelo usuário em `Widget 2.zip`.

- `index.html` — HTML atual
- `style.css` — CSS atual
- `script.js` — JavaScript atual
- `preview.html` — ambiente local de teste; simula `container`, `ctx`, telemetria e respostas do USNO. Não altera os três arquivos do widget.

## Objetivo

Usar este projeto no VS Code/Cline para fazer alterações controladas e testar o resultado antes de publicar no ThingsBoard.

## Regra de trabalho

Não modificar código não relacionado ao problema solicitado. Fazer uma alteração por vez e testar antes da próxima.
